# Statement of Work — Mobile Checkout Optimization for Northvale Tea
Between Dana Reyes, Reyes Web Studio ("Provider") and Northvale Tea Ltd ("Client")
Date: 21 September 2026 · Reference: proposal dated 21 September 2026, Option 2 — Diagnostic + Implementation

## 1. Objective
Move Northvale Tea's mobile checkout conversion rate meaningfully toward the 2.9% desktop benchmark (currently 1.1%), based on a data-driven audit rather than guesswork, with fixes implemented, QA'd, and stable ahead of the 7 November Black Friday creative launch — without a rebrand or new theme risk.

## 2. Deliverables
| # | Deliverable | Description | Acceptance criteria |
|---|-------------|-------------|---------------------|
| 1 | Mobile checkout funnel audit | Full audit of the mobile checkout funnel using Client's analytics and session recordings, covering every step from cart to order confirmation | Written findings identify the step(s) driving the 1.1% vs 2.9% gap, with supporting data cited for each claim |
| 2 | Root-cause report | Root-cause findings on whether the payment step is the primary issue, plus a prioritised fix list with expected impact | Report delivered in writing and walked through live on a call with Priya (and Mo if available) |
| 3 | Implementation of priority fixes | Build of the top-priority fixes identified in the audit, within Northvale's current design language, deployed with coordination from Northvale's part-time dev | Fixes deployed to the live mobile checkout, matching existing design language, no new theme or rebrand introduced |
| 4 | Mobile QA round | One full round of QA testing the implemented fixes across major mobile devices and browsers | QA checklist completed and shared, with any defects found in this round resolved before final delivery |

## 3. Out of scope
- Payment provider changes or evaluation (out of scope given the provider's March lock-in)
- Rebrand or new theme — all work stays within the current design
- Desktop checkout work — desktop is already converting well
- New app installs beyond what a given fix requires
- Marketing, ad creative, or ad spend strategy
- Support beyond delivery of this engagement (e.g. Black Friday weekend on-call is Option 3, not included here) unless agreed separately as a change order

Anything not listed in section 2 is out of scope and handled via a change request (section 8).
